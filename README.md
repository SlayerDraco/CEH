## How to use this repo

1. **Learn / revise** from `CEHv13_Notes.md` and `CEH_v13_Practice_Guide.pdf`.
2. **Follow the 21-Day Plan** inside the Practice Guide (~2 hrs/day).
3. **Sit each mock** under exam conditions: **125 questions / 4 hours** (≈ 1 min 55 sec per question). Keep the answer key closed until you finish.
4. **Score and review:** benchmark **106/125 ≈ 85%**. Tally misses by module; for any module with ≥3 misses, re-study its *Exam Traps* and *Confused Concepts* in the Practice Guide.

### Scoring benchmark
*Study benchmark only — NOT the official EC-Council passing score.*

| Score / 125 | Interpretation |
|---|---|
| 106–125 | Target range (≥85%) |
| 100–105 | Close; revise weak areas |
| 94–99 | Below target; revision required |
| < 94 | Major revision required |
